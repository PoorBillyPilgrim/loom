## Agent skills

### Issue tracker

Issues are tracked in GitHub Issues for PoorBillyPilgrim/loom, managed with the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Uses the five default triage labels: needs-triage, needs-info, ready-for-agent, ready-for-human, wontfix. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `GLOSSARY.md` and `docs/adr/` at the repo root. See `docs/agents/domain.md`.

## Planning

Tasks and tickets in this repo don't need to stay near ~200 changed lines (overrides the global rule). Size them by what makes one coherent, testable slice.
